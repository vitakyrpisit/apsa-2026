На основе проведенного исследования и детального технического анализа разработан AI Freelancer OS v0.1 — автономная операционная система фрилансера и полноценный исполняемый репозиторий проекта.
Платформа развернута в приложении и включает как интерактивную панель управления с симулятором полного жизненного цикла, так и 16 готовых исполняемых файлов бэкенда на Python 3.12 / FastAPI / SQLAlchemy / PyTest, которые можно выгрузить в один клик в виде ZIP-архива.
Архитектура и ключевые компоненты системы
Многомаркетплейсный слой (Marketplace Adapter Layer):
TaskBounty (GitHub issues, E2B-песочница, 80% агенту, instant USDC на Base).
BasedAgents (Ed25519 криптографическая подпись, Base escrow, 90% агенту).
AgentGigs (Stripe Connect, автономный запуск через REST API, 90% агенту).
ClawGig (42-tool MCP сервер, USDC escrow, 90% агенту).
Upwork MCP (Официальный MCP протокол с режимом обязательного подтверждения человеком для контрактов).
Superteam Earn (Web3 bounties и прямые AGENT_ONLY задачи).
Opportunity Engine (Математический расчет Expected Value):
Агент отсекает задачи с низким EV, не берет неопределенные задания и не тратит токены впустую.
Prompt Injection Firewall & Security Vault:
Любое задание клиента или README считается недоверенным вводом.
Фаервол перехватывает попытки манипуляции системным промптом или кражи API-ключей/Vault KMS еще до передачи в планировщик.
Изолированная песочница (Docker / E2B Sandbox):
Строгие лимиты ресурсов: максимум 2 CPU, 4 ГБ RAM, таймаут 1800 сек, изоляция сети от внутренних БД и Redis.
Независимый QA Oracle:
Агент-программист не оценивает собственную работу. Отдельный QA-агент верифицирует критерии приемки (AC1–AC4) по git diff и логам тестов.
P&L Ledger & Unit Economics:
Учет каждого цента: стоимость инференса модели (Gemini API), время работы контейнеров, комиссия биржи 
 чистая прибыль в казну.

Быстрый запуск на локальной машине
code
Bash
# 1. Распаковать скачанный архив и скопировать env:
cp .env.example .env

# 2. Поднять стек в Docker:
docker compose up -d

# 3. Инициализировать базу данных:
docker compose exec api python db/seed_data.py

# 4. Запустить автономный сквозной тест:
docker compose exec worker pytest tests/e2e/test_autonomous_job.py -v
В интерактивном интерфейсе можно протестировать расчет формулы EV, запустить симуляцию автономного цикла с живым выводом терминала и проверить реакцию фаервола на вредоносный промпт.
